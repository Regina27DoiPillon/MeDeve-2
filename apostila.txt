📌 2. VARIÁVEIS EM PHP
Uma variável é um espaço usado para guardar informações.
Exemplo básico:
<?php
$nome = "Maria";
$idade = 15;
?>
<?php

$nome = "Maria";
$idade = 15;

?>
Explicação:
$nome → nome da variável
"Maria" → valor armazenado
* Toda variável em PHP começa com $
Em PHP:
● Variáveis são precedidas pelo símbolo de cifrão ($).
● O $nome representa o nome da variável.
● O valor armazenado na variável é o dado propriamente dito, como "Maria".
Em PHP, as variáveis são identificadas pelo símbolo de cifrão ($), seguido pelo nome da
variável (exemplo: $nome). O valor atribuído à variável, como "Maria", é o dado que ela
armazena.

Regra fundamental: Toda variável em PHP deve começar com o $.
✅ O valor da variável pode mudar durante o programa.
📌 3. O QUE SÃO LISTAS E VETORES?
Em PHP, listas e vetores são chamados de arrays.
👉 Um array permite guardar vários valores em uma única variável.
Sem array (forma incorreta):
$aluno1 = "Ana";
$aluno2 = "Bruno";
$aluno3 = "Carlos";
Com array (forma correta):
$alunos = ["Ana", "Bruno", "Carlos"];
* ✅ Código mais organizado

* ✅ Menos repetição
* ✅ Base de sistemas profissionais
📌 4. ARRAY INDEXADO (VETOR)
O array indexado usa números como índice, começando sempre em 0.
<?php
$cores = ["Azul", "Verde", "Vermelho"];

echo $cores[0]; // Azul
echo $cores[1]; // Verde
?>
Explicação:
* $cores[0] → primeiro valor
* $cores[1] → segundo valor
📌 O computador sempre começa a contar do zero.
📌 5. ARRAY ASSOCIATIVO (CHAVE → VALOR)
O array associativo funciona como um cadastro.
<?php
$cliente = [
"nome" => "Ana",
"email" => "ana@email.com",
"saldo" => 150.00
];

echo $cliente["nome"];
?>
Explicação:

* "nome" → chave
* "Ana" → valor
* A chave funciona como o nome de um campo no banco de dados
✅ Muito parecido com uma tabela de sistema real.
📌 6. ARRAY MULTIDIMENSIONAL
(Lista de registros)
Um array multidimensional é um array dentro de outro array.
<?php
$clientes = [
[
"id" => 1,
"nome" => "Ana",
"saldo" => 150
],
[
"id" => 2,
"nome" => "Bruno",
"saldo" => -80
]
];
?>

Interpretação:
* Cada bloco representa um cliente
* Funciona como linhas de uma tabela
✅ Aqui começamos a simular um banco de dados.

📌 2. O QUE SÃO ESTRUTURAS DE REPETIÇÃO?
Estruturas de repetição servem para executar o mesmo código várias vezes, de forma
automática.
Exemplo da vida real:
“Para cada aluno da lista, mostrar o nome”
No PHP, uma das estruturas mais usadas para trabalhar com listas é o foreach.

📌 3. O COMANDO foreach
O foreach percorre todos os valores de um array, um por um.
Estrutura básica:
foreach ($array as $valor) {
// código
}
● $array → lista de dados
● $valor → recebe cada item da lista
📌 4. foreach COM ARRAY INDEXADO
Exemplo:
<?php
$alunos = ["Ana", "Bruno", "Carlos"];

foreach ($alunos as $aluno) {
echo $aluno . "<br>";
}
?>
Explicação linha a linha:
● O foreach pega cada nome do array $alunos
● A variável $aluno recebe um nome por vez
● O echo mostra o nome na tela
✅ Resultado:
Ana
Bruno
Carlos
📌 5. foreach COM ARRAY ASSOCIATIVO
Exemplo:
<?php

$cliente = [
"nome" => "Ana",
"email" => "ana@email.com",
"saldo" => 150
];

foreach ($cliente as $campo => $valor) {
echo $campo . ": " . $valor . "<br>";
}
?>
Explicação:
● $campo → nome da chave (nome, email, saldo)
● $valor → valor correspondente
✅ Muito parecido com a leitura de campos de um banco de dados.
📌 6. foreach COM ARRAY MULTIDIMENSIONAL
(Simulação de Tabela)
Exemplo:
<?php
$clientes = [
[
"id" => 1,
"nome" => "Ana",
"saldo" => 150
],
[
"id" => 2,
"nome" => "Bruno",

"saldo" => -80
]
];

foreach ($clientes as $cliente) {
echo "Nome: " . $cliente["nome"] . "<br>";
echo "Saldo: " . $cliente["saldo"] . "<br>";
echo "<hr>";
}
?>
📌 Cada repetição representa uma linha da tabela.
✅ Isso simula:
SELECT * FROM clientes;

📘 AULA 04

Sessões, Login e Controle de Acesso em PHP

Autenticação de usuários em sistemas web

📌 1. O QUE É LOGIN EM UM SISTEMA?
Login é o processo de identificar um usuário dentro do sistema.
Normalmente envolve:
● Usuário
● Senha
📌 Quando o login é válido, o sistema: ✅ Permite acesso
✅ Guarda informações do usuário
✅ Controla o que ele pode ou não fazer

📌 2. O QUE É UMA SESSÃO?
Uma sessão é uma forma do servidor lembrar quem é o usuário enquanto ele navega pelo
sistema.
👉 Sem sessão:
● Cada página “esquece” o usuário
👉 Com sessão:
● O sistema sabe quem está logado
● O acesso é controlado

📌 3. INICIANDO UMA SESSÃO EM PHP
Para usar sessões em PHP, é obrigatório iniciar a sessão.
<?php
session_start();
?>
📌 Esse comando deve ficar no início do arquivo, antes de qualquer HTML.
✅ Normalmente fica no arquivo config.php.

📌 5. CRIANDO A TELA DE LOGIN
📄 login.php
<?php
include "config/config.php";
include "data/dados.php";
$erro = "";

if ($_POST) {
foreach ($usuarios as $user) {
if (
$_POST["usuario"] == $user["usuario"] &&
$_POST["senha"] == $user["senha"]
) {
$_SESSION["usuario"] = $user["usuario"];
$_SESSION["perfil"] = $user["perfil"];
header("Location: pages/dashboard.php");
exit;
}
}
$erro = "Usuário ou senha inválidos!";
}
?>
Explicação:
● Verifica se o formulário foi enviado
● Percorre os usuários com foreach
● Compara usuário e senha
● Cria a sessão
● Redireciona para o sistema
📌 6. USANDO A SESSÃO
Após o login, os dados ficam disponíveis em qualquer página.
<?php

echo $_SESSION["perfil"];
?>
✅ O sistema agora “sabe” quem está logado.

📌 1. O QUE É BOOTSTRAP?
O Bootstrap é um framework front-end, ou seja, uma ferramenta que ajuda a criar a parte
visual do sistema.
👉 Ele é usado para:
● Deixar páginas bonitas
● Organizar o layout
● Criar sites responsivos (computador e celular)
📌 O Bootstrap não substitui o PHP.
Eles trabalham juntos:
Tecnologia Responsabilidade
PHP Lógica e dados
Bootstrap Aparência e layout

📌 2. FRONT-END x BACK-END
✅ Back-end
● PHP
● Processa dados
● Login, regras, cálculos
✅ Front-end
● HTML
● CSS
● Bootstrap
● Aparência do sistema
📌 Nesta aula, o foco é o front-end com Bootstrap.

📌 3. COMO USAR BOOTSTRAP (CDN)

A forma mais simples é usando CDN.
📄 header.php
<!DOCTYPE html>
<html lang="pt-br">
<head>
<meta charset="UTF-8">
<title>Sistema Financeiro</title>
<!-- Bootstrap CSS -->
https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css
</head>
<body>
📌 Com isso, todo o sistema já pode usar Bootstrap.

📌 4. CONTAINER – CENTRALIZANDO O
CONTEÚDO

O Bootstrap usa containers para organizar o conteúdo.
<div class="container">
<h1>Meu Sistema</h1>
</div>
✅ Centraliza
✅ Define largura máxima
✅ Deixa o layout organizado

📌 5. SISTEMA DE GRID (ROW E COL)
O Bootstrap trabalha com linhas (row) e colunas (col).
<div class="container">
<div class="row">
<div class="col-md-6">Coluna 1</div>
<div class="col-md-6">Coluna 2</div>
</div>
</div>

📌 col-md-6 significa:
● 6 colunas de um total de 12
● Layout responsivo
✅ Funciona no computador e no celular.

📌 6. BOTÕES COM BOOTSTRAP
<button class="btn btn-primary">Salvar</button>
<button class="btn btn-success">Cadastrar</button>
<button class="btn btn-danger">Excluir</button>
📌 Sem escrever CSS, o botão já fica:
● Colorido
● Padronizado
● Profissional

</form>
✅ Layout limpo
✅ Fácil de usar
✅ Ideal para sistemas
